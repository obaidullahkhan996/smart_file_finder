A simple Python project that helps you find files inside a folder and its subfolders. Instead of searching manually, you can enter a filename or file extension and let the program find matching files for you.

Features

Search files by full or partial filename

Search by file extension such as .pdf, .py, or .txt

Search inside folders and subfolders

Case-insensitive searching

Ignore .git folders

Display full file paths

Count matching files

Validate folder paths

Technologies Used

Python

os module

How to Use

Run main.py

Enter the filename or extension you want to search for.

Enter the folder path you want to search.

The program displays matching files and their locations.
